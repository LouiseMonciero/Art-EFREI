## Configuration

- Ajout du `.env`

```.env
# HelloAsso : identifiants API (Mon compte > Intégrations et API)
# Ne jamais commiter ce fichier ni préfixer ces variables par VUE_APP_
HELLOASSO_CLIENT_ID=
HELLOASSO_CLIENT_SECRET=
HELLOASSO_ORGANIZATION_SLUG=
HELLOASSO_MEMBERSHIP_FORM_SLUG=

# Valeur affichée si HelloAsso est indisponible
VUE_APP_ADHERENTS_DEFAUT=+50
```
